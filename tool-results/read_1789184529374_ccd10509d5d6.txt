     3→     3→## Project Overview
     4→     4→A full-featured clone of https://thesiswritingservice.com.pk/ built with Next.js 16,
     5→     5→TypeScript, Tailwind CSS 4, shadcn/ui, Prisma (SQLite), and Framer Motion.
     6→     6→The site is a single-page application with an interactive price calculator, an order
     7→     7→dialog that persists submissions to a database, a contact form, and a newsletter signup.
